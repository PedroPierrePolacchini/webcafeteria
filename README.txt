Projeto: Cafeteria Virtual

Tecnologias utilizadas:
- HTML
- CSS
- JavaScript
- PHP
- MariaDB

Funcionalidades:
- Cadastro de usuários
- Login
- Catálogo de produtos
- Pagina do produto
- Avaliações de produtos
- Carrinho de compras
- Cupons de desconto

Para executar:
1. Importar cafeteria.sql no MariaDB.
2. Configurar as credenciais em includes/db.php.
3. Acessar public/index.php.
